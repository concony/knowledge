# フォルダ構成と役割分担

## フォルダ構成

```
00_Inbox   ← とりあえず書いたものを置く
10_Notes   ← ちゃんと書き直した知見ノート（法則・ケース・ルール）
20_Views   ← Viewノート
90_Archive ← 古くなったもの、過去ログ
```

フォルダの役割は、**処理状態と大きな用途を分けること**に限定する。ノートの意味内容による細かい分類はタグで行う。

## 10_Notesをさらに分けない理由

法則・ケース・ルールは相互に変換されることがある。最初はケースとして書いたものが後で法則になることがある。フォルダで分けると分類変更のコストが高くなる。種類はタグで管理する。

## 90_Archiveを使う理由

削除ではなくArchiveにする。過去の思考や運用の変化そのものが、後でケースとして意味を持つ可能性がある。

## フォルダ・タグ・View・リンクの役割分担

| 仕組み | 役割 |
|--------|------|
| フォルダ | 処理状態・大きな置き場所を決める |
| タグ | 検索・抽出の条件を付ける |
| View | 文脈・構造・優先順位を与える |
| リンク | 知識同士の関係を直接つなぐ |
