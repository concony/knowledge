# 欲求分類は上位目的に立ち返るための軸である

欲求分類は、人間の欲求を完全に網羅して固定するための表ではなく、タスクや関心が膨張したときに、自分が目指すべき上位目的へ立ち返るための軸である。

タスクが増えすぎると、個々のタスクがすべて「やるべきもの」に見えてくる。そのときに必要なのは、タスクを細かく分類することではなく、それらが自分の人生のどの上位目的に寄与しているのかを見直すことである。

## なぜアドラー心理学を参照するか

この欲求分類では、アドラー心理学を単なる一般理論としてではなく、自分が長く影響を受けてきた考え方として参照する。

高校時代に『嫌われる勇気』を読んだことをきっかけに、関連書籍を読み続けてきた。そのため、共同体感覚、貢献、課題の分離、劣等感との付き合い方といった観点は、自分にとって抽象的な心理学知識ではなく、人生設計や優先順位づけを考えるときの土台になっている。

このノートでアドラー心理学を使う理由は、人間一般の欲求を厳密に分類するためではない。自分のタスクや欲求が、不安補償や私的な優越に向かっているのか、それとも共同体感覚・貢献・協力の方向に向かっているのかを見分けるためである。

## MECEは絶対条件ではなく評価観点である

欲求は現実には重なり合う。安心、自律、成長、親密、意味、快のような欲求は、1つの経験や行動の中で同時に満たされることが多い。そのため、欲求を完全に漏れなくダブりなく分類することは難しい。

ただし、MECEという観点は無意味ではない。分類軸がよいかどうかを評価する観点としては使える。

- 重要な欲求を見落としていないか
- 似た欲求を不要に重複させていないか
- 境界が曖昧すぎて判断に使えなくなっていないか
- タスクや人生設計を見直すときに、少数の上位目的へ収束するか

つまり、MECEは欲求分類の完成条件ではなく、欲求分類を改善するためのチェック観点である。

## 複数の分類軸で捉える

欲求を1つの分類表に押し込むより、複数の軸の組み合わせとして捉える方が実用的である。

### 何が満たされるか

心理的に何が充足されるかを見る軸。

| 軸 | 内容 |
|----|------|
| **安心** | 脅威や不安が少なく、心身や生活の基盤が守られている |
| **自律** | 自分で選び、決め、コントロールしている |
| **有能感 / 成長** | できることが増え、前に進んでいる |
| **所属 / 親密** | 他者とつながり、受け入れられている |
| **貢献 / 意味** | 自分の行動が他者や共同体に役立っている |
| **快 / 活力** | 感覚的・情動的に満たされ、生命力が高まっている |

この軸は、自己決定理論の自律・有能感・関係性や、アドラー心理学の共同体感覚とも接続しやすい。

### どこで満たされるか

欲求が満たされる人生領域を見る軸。

| 軸 | 内容 |
|----|------|
| **仕事** | 価値提供、能力発揮、報酬、キャリア |
| **交友 / 共同体** | 友人、仲間、社会的つながり |
| **愛 / 親密な関係** | パートナー、家族、深い関係性 |
| **自己** | 自分自身との関係、心身の健康、住環境、家計、日常の安定 |

この軸は、アドラー心理学におけるライフタスクに近い。仕事・交友・愛は他者との関係の中で欲求が満たされる領域であり、自己はそれらの前提になる自分自身との関係や生活基盤を扱う領域である。人生設計では、欲求そのものだけでなく、どの生活領域でそれを満たすのかも重要になる。

### どちらへ向かっているか

欲求の向きを見る軸。

| 向き | 内容 |
|------|------|
| **不安補償 / 私的な優越** | 劣等感、不安、承認欲求、完璧主義を埋めるために動いている |
| **共同体感覚 / 貢献 / 協力** | 他者や共同体とのつながりの中で、よりよく生きる方向に動いている |

アドラー心理学を中心に置くなら、この軸が特に重要になる。同じ「成長」でも、不安を打ち消すための成長と、他者に貢献できる範囲を広げる成長では意味が違う。同じ「仕事」でも、私的な優越を得るための仕事と、共同体への貢献としての仕事では、最終的な方向が違う。

## タスク膨張への使い方

タスクが増えすぎたときは、次の順で見る。

1. このタスクは、どの欲求を満たそうとしているのか
2. その欲求は、どの人生領域で満たされるものか
3. その動機は、不安補償や私的な優越に寄っていないか
4. 共同体感覚・貢献・協力の方向に置き直せるか
5. 置き直せないなら、本当にやる必要があるか

この問いを通すことで、タスクを単なるTODOではなく、上位目的に対する手段として見直せる。欲求や人生領域に本質的に寄与しないタスクは、やらない候補になる。

## 今のモデルとの関係

[[人生の目的を幸せの時間積分として捉える]]の欲求リストや、[[タスクを欲求と事象ドメインの2層で分類する]]のドメイン分類は、固定された完成版ではない。

この分類は、[[体系は不完全なまま運用しながら改善する]] という考え方に基づく暫定体系である。現時点で最低限有用な軸として運用し、実際のタスク整理や人生設計の中で分類しにくい欲求、重複している軸、判断に効かない項目が見つかれば、その経験をもとに改善する。

今後は、欲求を単一のリストとして完成させることを目指しすぎない。複数の分類軸を使いながら、自分の人生設計・優先順位づけ・タスク削減に使える形へ更新し続ける。
