# 欲求分類は上位目的に立ち返るための軸である

欲求分類は、人間の欲求を完全に網羅して固定するための表ではなく、タスクや関心が膨張したときに、自分が目指すべき上位目的へ立ち返るための軸である。

この分類は、[[体系は不完全なまま運用しながら改善する]] という考え方に基づく暫定体系である。現時点で最低限有用な軸として運用し、実際のタスク整理や人生設計の中で分類しにくい欲求、重複している軸、判断に効かない項目が見つかれば、その経験をもとに改善する。

## 第一分類は「自己で完結するか」で分ける

欲求を考えるとき、まず「自己で完結する欲求」と「他者との関わりの中で成立する欲求」に分ける。

分類基準は、その欲求が成立するために、他者や共同体が構成要素として必要かどうかである。

- **自己で完結する欲求**：他者がいなくても成立する欲求
- **他者との関わりの中で成立する欲求**：他者や共同体との関係がなければ成立しない欲求

行動としては同じものでも、どの欲求を満たそうとしているかで分類は変わる。たとえば勉強は、知的好奇心や向上欲求を満たすなら自己で完結する欲求に近い。一方で、他者から評価されたい、共同体に貢献したいという動機が中心なら、他者との関わりの中で成立する欲求に関係する。

## 自己で完結する欲求

| 欲求 | 内容 |
|------|------|
| **刹那的・身体的快楽** | 体験、休息、快楽、食事など、身体的・感覚的に満たされる欲求 |
| **自由** | 自分で選び、決め、行動できる状態を求める欲求 |
| **統治** | 自分の周囲の物事を秩序立て、予測可能でコントロールしやすい状態に置きたい欲求 |
| **向上** | 知的好奇心、学習、成長、できることを増やしたい欲求 |
| **目標達成** | 自分で設定した目標を達成し、完了感や前進感を得たい欲求 |

これらは他者と共有されることもあるが、欲求そのものは自己の内部で成立する。たとえば旅行は他者と行くこともあるが、身体的快楽や体験欲求として見れば自己で完結する側面がある。

## 他者との関わりの中で成立する欲求

| 欲求 | 内容 |
|------|------|
| **共同体への所属** | 自分が共同体の一員として受け入れられ、居場所があると感じたい欲求 |
| **貢献感** | 自分の行動が他者や共同体の役に立っていると感じたい欲求 |
| **共同体幸福** | 自分だけでなく、共同体や大切な他者がよい状態であることを望む欲求 |

共同体への所属には、存在価値の承認欲求と機能価値の承認欲求が含まれる。

- **存在価値の承認欲求**：自分が存在していてよい、ここにいてよいと感じたい欲求
- **機能価値の承認欲求**：自分の能力・成果・役割が認められ、共同体の中で機能していると感じたい欲求

この分類では、アドラー心理学を単なる一般理論としてではなく、自分が長く影響を受けてきた考え方として参照する。共同体感覚、貢献、課題の分離、劣等感との付き合い方は、他者との関わりの中で成立する欲求を見分けるうえで重要な土台になる。

## 統治が他者に向くと支配に変わる

統治の欲求は、自分の周囲の物事を秩序立て、予測可能な状態にしたい欲求としては有用である。生活環境を整える、タスクを整理する、知識体系を構造化する、といった形なら、自己で完結する欲求として扱える。

しかし、統治の対象が他者に向くと、他者を自分の予測可能なコントロール下に置きたいという支配的な欲求に変わる。これは他者との関わりの中で成立する欲求だが、共同体感覚や貢献とは方向が違う。

他者を操作しようとしていないか、自分の不安を埋めるために相手の選択をコントロールしようとしていないかは、注意して見る必要がある。ここでは [[常により上位の目的を意識する]] だけでなく、課題の分離や共同体感覚の観点が重要になる。

## タスク膨張への使い方

タスクが増えすぎたときは、次の順で見る。

1. このタスクは、現在の欲求を直接満たすものか、将来の欲求充足への投資か、維持か、リスク低減か
2. 対象になっている欲求・資産・基盤は何か
3. その欲求は、自己で完結する欲求か、他者との関わりの中で成立する欲求か
4. そのタスクは、上位目的である [[人生の目的を幸せの時間積分として捉える]] ことに本当に寄与するか

すべてのタスクが欲求を直接満たすわけではない。仕事でお金を得る、学習して能力を増やす、健康管理をする、といったタスクは、将来の $h(t)$ を押し上げるための投資や維持として意味を持つ。タスク分類では [[タスクを効用への寄与経路と事象ドメインで分類する]] を使い、欲求分類はそのタスクが最終的にどの欲求や上位目的へ接続しているかを見るために使う。
