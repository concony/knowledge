# タスクを欲求と事象ドメインの2層で分類する

タスクを整理するときは、欲求（なぜそれをしたいのか）と事象ドメイン（現実のどの領域で行うのか）の2層で捉える。

欲求だけを見ると現実の行動に落ちにくい。事象ドメインだけを見ると、なぜそれが重要なのかが見えにくい。2層で見ることで、タスクがどの上位目的に寄与しているのかを判断しやすくなる。

## Layer 1：欲求

欲求は [[欲求分類は上位目的に立ち返るための軸である]] の暫定分類を使う。

### 自己で完結する欲求

- 刹那的・身体的快楽
- 自由
- 統治
- 向上
- 目標達成

### 他者との関わりの中で成立する欲求

- 共同体への所属
- 貢献感
- 共同体幸福

タスクを分類するときは、まず「このタスクはどの欲求を満たそうとしているのか」を見る。複数の欲求に関係する場合は、主目的になっている欲求と、副次的に満たされる欲求を分ける。

## Layer 2：事象ドメイン

タスクが所属する現実世界の領域は、当面は4つに集約する。

| ドメイン | 範囲 |
|----------|------|
| **暮らし** | 心身の健康管理、睡眠、運動、食事、医療、家事、住環境、家計 |
| **能力** | 知識・スキルの獲得、学習、技術的探求、思考の言語化 |
| **仕事** | 業務遂行、キャリア判断、職場環境、価値提供、報酬 |
| **関係と体験** | 家族・パートナー・友人との時間、旅行、娯楽、共同体との関わり |

ドメインは、タスクを実際にどこで実行するかを見るための軸である。同じ欲求でも、どのドメインで満たすかによって、取るべき行動は変わる。

## 欲求とドメインの対応を見る

| 欲求 | 主に関係しやすいドメイン | 例 |
|------|--------------------------|----|
| 刹那的・身体的快楽 | 暮らし、関係と体験 | 食事、休息、旅行、娯楽 |
| 自由 | 暮らし、仕事、能力 | 裁量を増やす、生活を軽くする、選択肢を増やす |
| 統治 | 暮らし、能力、仕事 | 部屋を整える、タスクを整理する、知識体系を作る |
| 向上 | 能力、仕事 | 学習、技術習得、経験値を増やす |
| 目標達成 | 能力、仕事、暮らし | 試験合格、プロジェクト完了、習慣達成 |
| 共同体への所属 | 関係と体験、仕事 | 家族・友人・職場・コミュニティとの関係 |
| 貢献感 | 仕事、関係と体験 | 価値提供、支援、役割を果たす |
| 共同体幸福 | 関係と体験、仕事、暮らし | 家族の生活を整える、共同体全体の状態をよくする |

この表は完成版ではない。実際に分類しにくいタスクが出てきたら、欲求分類やドメイン分類を更新する。

## タスク分類の指針

1. タスクが所属する事象ドメインを確認する
2. そのタスクが満たそうとしている欲求を確認する
3. 主目的の欲求と、副次的な欲求を分ける
4. そのタスクが [[人生の目的を幸せの時間積分として捉える]] ことに寄与しているかを見る
5. どの欲求にも本質的に寄与しないタスクは、やらない候補にする

迷ったら「何のためにやるのか」を一段上げる。英語学習は、向上欲求を満たすためか、仕事の自由度を上げるためか、機能価値の承認を得るためかで意味が変わる。旅行先を調べることも、刹那的・身体的快楽のためか、共同体幸福のためかで位置づけが変わる。

## 注意点

分類はタスクを増やすためではなく、減らすために使う。

分類してみて、どの上位目的にも寄与していないタスクや、支配・不安補償・惰性に寄っているタスクが見つかったら、やらない候補にする。逆に、慢性的に不足している欲求が見つかったら、その欲求を満たすドメインへの時間配分を見直す。
