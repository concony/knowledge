# タスクを欲求と事象ドメインの2層で分類する

タスクを整理するとき、根源的な欲求（なぜ幸せを感じるのか）と事象ドメイン（現実のどの領域か）の2層で捉えることで、タスクの位置づけと優先度が明確になる。

## なぜ2層か

幸せの構成要素を分解する軸は複数ある。心の欲求の充足という側面（なぜそれが幸せにつながるのか）と、現実の事象的な見方（仕事・暮らし・能力など）は異なる切り口である。

タスクの分類には事象ドメインが直接的に相性がよい。一方で、根源的な欲求の構造を持っておくと、あるドメインへの投資がなぜ重要なのか、どの欲求が不足しているのかを判断する基準になる。

## Layer 1：欲求

[[人生の目的を幸せの時間積分として捉える]]で分析した、$h(t)$ を構成する7つの欲求。

- **基盤**：安心
- **駆動**：自律、成長、没頭、親密、快
- **統合**：意味

## Layer 2：事象ドメイン

タスクが所属する現実世界の領域。4つに集約する。

| ドメイン | 範囲 |
|----------|------|
| **暮らし** | 心身の健康管理（睡眠、運動、食事、医療）、生活環境の維持（家事、住環境）、家計管理 |
| **能力** | 知識・スキルの獲得、学習、技術的探求 |
| **仕事** | 業務遂行、キャリア判断、職場環境 |
| **関係と体験** | 家族・パートナー・友人との時間、旅行、娯楽 |

経済的安定は独立したドメインにしない。能力と仕事の成果として得られるものとして扱う。

## ドメインから欲求への寄与マップ

| ドメイン | 安心 | 自律 | 成長 | 没頭 | 親密 | 快 | 意味 |
|----------|------|------|------|------|------|-----|------|
| **暮らし** | ◎ | | | | | ○ | |
| **能力** | ○ | ◎ | ◎ | ○ | | | |
| **仕事** | ○ | ○ | ◎ | ◎ | | | △ |
| **関係と体験** | | | | | ◎ | ◎ | △ |

◎ = 主要な寄与　○ = 副次的な寄与　△ = 潜在的

### 読み取れること

- **成長**は「能力」と「仕事」の両方から充足される。エンジニアの場合この2つの重なりが特に大きい
- **親密と快**は「関係と体験」にほぼ集約される。他ドメインからの寄与が小さいため、意識的に時間を確保しないと不足しやすい
- **仕事**は多くの欲求に同時に寄与する。人生の大きな時間を占めるため、仕事の充実は $h(t)$ へのインパクトが大きい
- **能力と仕事は正のフィードバックループ**を形成する（能力 → 仕事が楽しい・自由 → 成長 → 能力）

## 各ドメインの理想状態チェックリスト

### 暮らし

- [ ] 慢性的な体の不調がない
- [ ] 十分な睡眠が取れている
- [ ] 定期的に運動している
- [ ] 食事が適当にならず、ちゃんと食べている
- [ ] 精神的に安定していて、漠然とした不安が少ない
- [ ] 住環境が清潔で快適に保たれている
- [ ] 家事がストレスなく回っている
- [ ] 経済的に将来の不安が小さい
- [ ] 健康診断を定期的に受けている

### 能力

- [ ] エンジニアとしての技術力が市場で高く評価される水準にある
- [ ] 関心のある技術領域の知識が自分の中で整理されている
- [ ] 新しい技術や概念を継続的にキャッチアップしている
- [ ] 思考を言語化・構造化する力がついている
- [ ] 知見の蓄積（このVaultなど）が進んでいる
- [ ] 学習に使える時間を定期的に確保できている

### 仕事

- [ ] 面白い・やりがいがあると感じる仕事に取り組めている
- [ ] やり方や進め方を自分で決められる裁量がある
- [ ] 仕事を通じて成長を実感できている
- [ ] 成果に対して納得できる報酬を得ている
- [ ] 尊敬できる人、刺激をもらえる人が周りにいる
- [ ] 技術的に停滞している感覚がない
- [ ] 過剰な負荷やストレスに潰されていない

### 関係と体験

- [ ] 妻と質の高い時間を定期的に過ごせている
- [ ] 日常の中で妻との関係が心地よい
- [ ] 旅行や外出など新しい体験を定期的にしている
- [ ] 大切な人との関係が良好である
- [ ] 一緒に過ごした楽しい思い出が増えている
- [ ] 孤立している感覚がない

## タスク分類の指針

1. **タスクを4つのドメインのいずれかに分類する**
2. **迷ったら「何のためにやるのか」を一段上げる**。英語学習 → 仕事のため → 「能力」。旅行先を調べる → 妻との時間のため → 「関係と体験」
3. **4つのどのドメインにも寄与しないタスクは「やらない」候補**
4. **ある欲求が慢性的に不足していると感じたら、対応するドメインへの時間配分を見直す**
5. **チェックリストで満たせていない項目があれば、そこに寄与するタスクの優先度を上げる**
