# タスクを効用への寄与経路と事象ドメインで分類する

タスクを整理するときは、そのタスクが [[人生の目的を幸せの時間積分として捉える]] ことにどう寄与するのかを見る。

すべてのタスクが、現在の欲求を直接満たすために行われているわけではない。仕事、学習、健康管理、家計管理のように、将来の欲求充足を可能にするための投資や、将来の $h(t)$ の毀損を防ぐための行動もある。

そのため、タスクは「どの欲求を満たすか」だけでなく、「現在または将来の $h(t)$ にどの経路で寄与するか」と「現実のどの領域で行うか」の組み合わせで捉える。

## Layer 1：効用への寄与経路

まず、そのタスクが $h(t)$ にどう寄与するかを見る。

| 寄与経路 | 関数的な意味 | 内容 | 例 |
|----------|----------------|------|----|
| **直接充足** | 現在の上振れ | その行動自体が現在の欲求を満たす | 食事、休息、旅行、会話、娯楽 |
| **投資** | 未来の上振れ | 将来の欲求充足能力を高める | 仕事でお金を得る、学習する、筋トレする、信用を積む |
| **維持** | 現在の下振れ防止 | 今ある基盤・状態の劣化を防ぎ、現在から近未来の $h(t)$ のベースラインを保つ | 睡眠、家事、健康管理、家計管理、生活環境の維持 |
| **リスク低減** | 未来の下振れ防止 | 将来の $h(t)$ や $T$ の大きな毀損を防ぐ | 通院、保険、バックアップ、問題の早期処理 |

この4分類は、「現在か未来か」と「上振れか下振れ防止か」で整理できる。直接充足と投資は $h(t)$ を押し上げる方向の行動であり、維持とリスク低減は $h(t)$ の低下を防ぐ方向の行動である。

たとえば仕事は、貢献感や所属を直接満たすこともあるが、お金・能力・信用を得て将来の欲求充足可能性を高める投資でもある。単一の欲求に直結させようとすると、こうした時間的な側面が見えなくなる。

## Layer 2：対象となる欲求・資産

次に、そのタスクが何を対象にしているのかを見る。

対象は、[[欲求分類は上位目的に立ち返るための軸である]] にある欲求そのものの場合もあれば、将来の欲求充足を可能にする資産の場合もある。

| 対象 | 内容 |
|------|------|
| **欲求** | 刹那的・身体的快楽、自由、統治、向上、目標達成、所属、貢献感、共同体幸福など |
| **お金** | 将来の選択肢、安心、体験、生活基盤を支える資源 |
| **能力** | 仕事、自由、向上、将来の選択肢を広げる資産 |
| **健康** | 現在の $h(t)$ と $T$ の両方を支える基盤 |
| **信用** | 仕事や共同体の中で、将来の機会や自由度を広げる資産 |
| **時間** | 他の欲求充足や投資を可能にする余白 |
| **関係性** | 所属、貢献感、共同体幸福を支える土台 |
| **生活基盤** | 暮らしの安定、予測可能性、安心を支える土台 |
| **哲学** | 世界の見方、意味づけ、公理・定理・価値判断の枠組み。同じ事象から得られる $h(t)$ を変える資産 |

「欲求を直接満たしていないタスク」に見えても、資産を増やしたり、基盤を維持したり、リスクを下げたりすることで、将来の $h(t)$ に寄与していることがある。

哲学は、[[人は主観世界の住人であり意味づけを選択できる]] という前提に立ち、事象をどう受け取り、どう意味づけるかに関わる資産である。

## Layer 3：事象ドメイン

最後に、そのタスクが現実のどの領域で行われるかを見る。

| ドメイン | 範囲 |
|----------|------|
| **暮らし** | 心身の健康管理、睡眠、運動、食事、医療、家事、住環境、家計 |
| **能力** | 知識・スキルの獲得、学習、技術的探求、思考の言語化 |
| **仕事** | 業務遂行、キャリア判断、職場環境、価値提供、報酬 |
| **関係と体験** | 家族・パートナー・友人との時間、旅行、娯楽、共同体との関わり |

事象ドメインは、タスクを実際にどこで実行するかを見るための軸である。同じ寄与経路でも、どのドメインで行うかによって、取るべき行動や優先度は変わる。

## 分類例

| タスク | 寄与経路 | 対象 | ドメイン |
|--------|----------|------|----------|
| 食事を楽しむ | 直接充足 | 刹那的・身体的快楽 | 暮らし、関係と体験 |
| 仕事で成果を出す | 投資 / 直接充足 | お金、能力、信用、貢献感 | 仕事 |
| 技術を学ぶ | 投資 / 直接充足 | 能力、向上、将来の自由 | 能力 |
| 睡眠を確保する | 維持 | 健康、生活基盤 | 暮らし |
| 家計を見直す | 維持 / リスク低減 | お金、生活基盤、将来の自由 | 暮らし |
| 病院に行く | リスク低減 / 維持 | 健康、T | 暮らし |
| 家族旅行を計画する | 直接充足 / 投資 | 体験、関係性、共同体幸福 | 関係と体験 |
| 出来事の意味づけを見直す | 維持 / 投資 | 哲学 | 能力、暮らし |

この表は完成版ではない。実際に分類しにくいタスクが出てきたら、寄与経路、対象、ドメインのいずれかを更新する。

## タスク分類の指針

1. そのタスクは、現在の欲求を直接満たすものか、将来の欲求充足への投資か、維持か、リスク低減かを見る
2. そのタスクが対象にしている欲求・資産・基盤を確認する
3. そのタスクが所属する事象ドメインを確認する
4. そのタスクが、長期的に $h(t)$ や $T$ を押し上げるかを見る
5. 寄与経路が説明できないタスクは、やらない候補にする

迷ったら「この行動は、いつ、どのように $h(t)$ に効くのか」を問う。今すぐ効くなら直接充足、将来の選択肢や能力を増やすなら投資、土台を保つなら維持、大きな毀損を防ぐならリスク低減として見る。

## 注意点

投資や維持の名目で、現在の $h(t)$ を毀損し続けることには注意する。将来のための行動でも、現在の幸せを大きく削り続けるなら、時間積分全体ではマイナスになる可能性がある。

また、投資は手段であって目的ではない。お金、能力、信用、生活基盤は、それ自体が最終目的なのではなく、現在または将来の欲求充足を可能にするための資産である。資産を増やすことが自己目的化していないかは、定期的に確認する。
