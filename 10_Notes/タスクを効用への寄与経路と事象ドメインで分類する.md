# タスクを効用への寄与経路と事象ドメインで分類する

タスクを整理するときは、そのタスクが [[人生の目的を幸せの時間積分として捉える]] ことにどう寄与するのかを見る。

すべてのタスクが、現在の欲求を直接満たすために行われているわけではない。仕事、学習、健康管理、家計管理のように、将来の欲求充足を可能にするための投資や、将来の $h(t)$ の毀損を防ぐための行動もある。

そのため、タスクは「どの欲求を満たすか」だけでなく、「現在または将来の $h(t)$ にどの経路で寄与するか」と「現実のどの領域で行うか」の組み合わせで捉える。

## Layer 1：効用への寄与経路

まず、そのタスクが $h(t)$ にどう寄与するかを見る。

| 寄与経路      | 関数的な意味   | 内容                                        | 例                         |
| --------- | -------- | ----------------------------------------- | ------------------------- |
| **直接充足**  | 現在の上振れ   | その行動自体が現在の欲求を満たす                          | 食事、休息、旅行、会話、娯楽            |
| **投資**    | 未来の上振れ   | 将来の欲求充足能力を高める                             | 仕事でお金を得る、学習する、筋トレする、信用を積む |
| **維持**    | 現在の下振れ防止 | 今ある基盤・状態の劣化を防ぎ、現在から近未来の $h(t)$ のベースラインを保つ | 睡眠、家事、健康管理、家計管理、生活環境の維持   |
| **リスク低減** | 未来の下振れ防止 | 将来の $h(t)$ や $T$ の大きな毀損を防ぐ                | 通院、保険、バックアップ、問題の早期処理      |

この4分類は、「現在か未来か」と「上振れか下振れ防止か」で整理できる。直接充足と投資は $h(t)$ を押し上げる方向の行動であり、維持とリスク低減は $h(t)$ の低下を防ぐ方向の行動である。

たとえば仕事は、貢献感や所属を直接満たすこともあるが、お金・能力・信用を得て将来の欲求充足可能性を高める投資でもある。単一の欲求に直結させようとすると、こうした時間的な側面が見えなくなる。

## Layer 2：対象となる欲求・資産

次に、そのタスクが何を対象にしているのかを見る。

対象は、[[欲求分類は上位目的に立ち返るための軸である]] にある欲求そのものの場合もあれば、将来の欲求充足を可能にする資産の場合もある。

| 対象       | 内容                                                 |
| -------- | -------------------------------------------------- |
| **欲求**   | 刹那的・身体的快楽、自由、統治、向上、目標達成、所属、貢献感、共同体幸福など             |
| **お金**   | 将来の選択肢、安心、体験、生活基盤を支える資源                            |
| **能力**   | 仕事、自由、向上、将来の選択肢を広げる資産                              |
| **健康**   | 現在の $h(t)$ と $T$ の両方を支える基盤                         |
| **信用**   | 仕事や共同体の中で、将来の機会や自由度を広げる資産                          |
| **時間**   | 他の欲求充足や投資を可能にする余白                                  |
| **関係性**  | 所属、貢献感、共同体幸福を支える土台                                 |
| **生活基盤** | 暮らしの安定、予測可能性、安心を支える土台                              |
| **哲学**   | 世界の見方、意味づけ、公理・定理・価値判断の枠組み。同じ事象から得られる $h(t)$ を変える資産 |

「欲求を直接満たしていないタスク」に見えても、資産を増やしたり、基盤を維持したり、リスクを下げたりすることで、将来の $h(t)$ に寄与していることがある。

寄与経路と対象は一対一対応ではない。同じ対象でも、どう扱うかによって寄与経路は変わる。たとえばお金は、収入を増やすなら投資、家計を整えるなら維持、保険や予備資金を用意するならリスク低減になる。健康も、運動によって将来の体力を増やすなら投資、睡眠で状態を保つなら維持、通院で大きな悪化を防ぐならリスク低減になる。

哲学は、[[人は主観世界の住人であり意味づけを選択できる]] という前提に立ち、事象をどう受け取り、どう意味づけるかに関わる資産である。

## Layer 3：事象ドメイン

最後に、そのタスクが現実のどの領域で行われるかを見る。

| ドメイン | 範囲 |
|----------|------|
| **暮らし** | 心身の健康管理、睡眠、運動、食事、医療、家事、住環境、家計 |
| **能力** | 知識・スキルの獲得、学習、技術的探求、思考の言語化 |
| **仕事** | 業務遂行、キャリア判断、職場環境、価値提供、報酬 |
| **関係と体験** | 家族・パートナー・友人との時間、旅行、娯楽、共同体との関わり |

事象ドメインは、タスクを実際にどこで実行するかを見るための軸である。同じ寄与経路でも、どのドメインで行うかによって、取るべき行動や優先度は変わる。

## 中間目的分類

寄与経路、対象、ドメインだけでは抽象度が高く、個別タスクに直接適用しにくい。そのため、実際のタスク整理では、まず「自分が近づきたい理想状態」や「大きな目標」に近い中間目的へ接続する。

中間目的は、個別タスクより抽象的だが、目的関数や欲求・資産よりは具体的な分類である。タスクはまずこの表のどれに貢献するかを見て、そのうえで寄与経路、対象、ドメインに戻す。

表の「主な寄与経路」と「主な対象」は、中間目的ごとの典型的な組み合わせである。Layer 1 と Layer 2 の対応を固定するものではなく、その中間目的を選んだときに立ち返りやすくするための要約として扱う。

表は完成版ではない。実際に分類しにくいタスクが出てきたら、中間目的、寄与経路、対象、ドメインのいずれかを更新する。

### 暮らし

| 中間目的             | 主な寄与経路     | 主な対象         | 内容                                  |
| ---------------- | ---------- | ------------ | ----------------------------------- |
| 心身の調子を良い状態に保つ    | 維持 / リスク低減 | 健康、T         | 睡眠、食事、運動、医療によって現在の $h(t)$ と健康寿命を支える |
| 生活環境を整える         | 維持         | 生活基盤、時間、統治欲求   | 住環境、家事、持ち物、日常の動線を整え、生活の摩擦を減らす       |
| 家計を安定させる         | 維持 / リスク低減 | お金、生活基盤、自由欲求   | 収支、貯蓄、固定費、保険を管理し、安心と将来の選択肢を守る       |
| 時間とエネルギーの余白を確保する | 維持 / 投資    | 時間、健康、自由欲求     | 詰め込みすぎを避け、休息、回復、重要タスクに使える余白を作る      |
| 休息して回復する         | 直接充足 / 維持  | 健康、刹那的・身体的快楽欲求 | 心身を回復させ、現在の幸福と継続可能性を支える             |
| 将来の大きな毀損を防ぐ      | リスク低減      | 健康、お金、生活基盤、T | 病気、事故、家計破綻、環境悪化などの大きな下振れを早めに防ぐ      |

### 仕事

| 中間目的 | 主な寄与経路 | 主な対象 | 内容 |
|----------|--------------|----------|------|
| 会社や顧客に貢献する | 直接充足 / 投資 | 貢献感欲求、信用、関係性 | 自分の仕事が他者や組織の役に立っている状態を作る |
| 仕事で成果を出す | 投資 / 直接充足 | 能力、信用、目標達成欲求 | 期待される成果を出し、前進感、達成感、信頼を得る |
| 仕事で評価を上げる | 投資 | 信用、お金、機能価値の承認欲求 | 成果、信頼、役割期待を積み上げ、機会や報酬につながる状態を作る |
| 仕事で給料を稼ぐ | 投資 / 維持 | お金、生活基盤、自由欲求 | 生活と将来の選択肢を支える収入を得る |
| 市場価値とキャリアの選択肢を広げる | 投資 / リスク低減 | 能力、信用、お金、自由欲求 | 今の会社に依存しすぎず、将来の働き方を選べる状態を作る |
| 働きやすい環境を作る | 維持 / リスク低減 | 健康、時間、関係性、生活基盤 | 業務量、人間関係、働き方を整え、仕事による継続的な消耗を抑える |

### 能力

| 中間目的 | 主な寄与経路 | 主な対象 | 内容 |
|----------|--------------|----------|------|
| 知識やスキルを増やす | 投資 / 直接充足 | 能力、向上欲求 | 学習や実践によって、できることと理解できることを増やす |
| 思考を言語化し、判断の質を上げる | 投資 / 維持 | 能力、哲学、統治欲求 | 考えを整理し、迷いやタスク膨張を扱いやすくする |
| 知識体系を整理する | 維持 / 投資 | 能力、統治欲求、時間 | ノートや分類を整え、必要な知識へ戻りやすくする |
| 哲学を磨き、意味づけを選択できるようにする | 維持 / 投資 | 哲学 | 事象の捉え方を整え、現在の $h(t)$ と行動可能性を高める |
| 好奇心や探求心を満たす | 直接充足 / 投資 | 向上欲求、能力 | 知りたい、試したい、理解したいという欲求を満たす |
| アウトプットの力を高める | 投資 / 直接充足 | 能力、貢献感欲求、信用 | 書く、作る、話す、実装する力を高め、他者に価値を届けやすくする |

### 関係と体験

| 中間目的 | 主な寄与経路 | 主な対象 | 内容 |
|----------|--------------|----------|------|
| 家族やパートナーとの関係を良い状態に保つ | 直接充足 / 維持 / 投資 | 関係性、所属欲求、共同体幸福欲求 | 近しい人との安心、信頼、共同体としての幸福を育てる |
| 友人や共同体とのつながりを保つ | 直接充足 / 維持 | 関係性、所属欲求、貢献感欲求 | 孤立を防ぎ、居場所や相互貢献の感覚を保つ |
| 他者に貢献する | 直接充足 / 投資 | 貢献感欲求、共同体幸福欲求、信用 | 自分の行動が他者や共同体の役に立つ状態を作る |
| 良い体験や思い出を増やす | 直接充足 | 体験、刹那的・身体的快楽欲求、関係性 | 旅行、娯楽、会話、イベントなどで現在の $h(t)$ を高める |
| 娯楽を楽しむ | 直接充足 | 刹那的・身体的快楽欲求、体験 | 楽しさや気晴らしを得て、現在の $h(t)$ を高める |

## タスク分類の指針

1. そのタスクが、どの中間目的に貢献するかを見る
2. その中間目的が、現在の欲求を直接満たすものか、将来の欲求充足への投資か、維持か、リスク低減かを見る
3. そのタスクが対象にしている欲求・資産・基盤を確認する
4. そのタスクが所属する事象ドメインを確認する
5. そのタスクが、長期的に $h(t)$ や $T$ を押し上げるかを見る
6. 中間目的や寄与経路が説明できないタスクは、やらない候補にする

迷ったら「この行動は、どの理想状態に近づくためのものか」を先に問う。そのうえで「いつ、どのように $h(t)$ に効くのか」を見る。今すぐ効くなら直接充足、将来の選択肢や能力を増やすなら投資、土台を保つなら維持、大きな毀損を防ぐならリスク低減として見る。

## 注意点

投資や維持の名目で、現在の $h(t)$ を毀損し続けることには注意する。将来のための行動でも、現在の幸せを大きく削り続けるなら、時間積分全体ではマイナスになる可能性がある。

また、投資は手段であって目的ではない。お金、能力、信用、生活基盤は、それ自体が最終目的なのではなく、現在または将来の欲求充足を可能にするための資産である。資産を増やすことが自己目的化していないかは、定期的に確認する。

「仕事で評価を上げる」は、他者からの承認そのものを追うためではなく、信用、機会、報酬、貢献可能性を高めるための中間目的として扱う。評価それ自体が目的化している場合は、機能価値の承認欲求を過剰に追求していないか確認する。
